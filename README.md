# 🛡️ FamilySafe: Real-Time Family Monitoring Ecosystem
**Team XCODER | Hacksagon 2026 @ ABV-IIITM Gwalior**

FamilySafe is a proactive family monitoring platform designed for Urban Family. It synchronizes Smartwatch and Smartphone data with a centralized **Real-Time Family Monitoring Dashboard**.

## ✨ Key Features
- **⌚ Live Vitals Sync:** Real-time Heart Rate & SpO2 tracking etc via smartwatch and Smartphone.
- **🏥 Medical Vault:** Secure storage for doctor prescriptions and PDF reports.
- **🚨 Emergency Alerts:** Automated SOS , disconnection alerts and Fall detection etc logic.
- **👥 Family Network:** Private SAFE-code based family linking.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB Atlas
